Conexión con GitHub (para guardar avances)

Para guardar el avance que ingreses acá hace falta un token de GitHub con permiso de escritura solo en este repositorio. Se guarda únicamente en este navegador, nunca se envía a otro lado salvo a la API de GitHub. Guía para crearlo: GitHub → tu foto de perfil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. En Repository access elige "Only select repositories" y selecciona Informe2_datos-de-bodega. En Permissions → Repository permissions → Contents elige "Read and write". Ponle una fecha de vencimiento y genera el token (empieza con github_pat_).
