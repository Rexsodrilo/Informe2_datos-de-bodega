Conexión con GitHub (para publicar datos)

Un solo token sirve para publicar todo lo que este sitio guarda: los datos del Excel (data.json.gz, con "Actualizar datos" de arriba) y el avance de Producción (botón "Guardar cambios" en produccion.html). Configúralo acá una sola vez. Se guarda únicamente en este navegador, nunca se envía a otro lado salvo a la API de GitHub.

Guía para crear el token: GitHub → tu foto de perfil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. En Repository access elige "Only select repositories" y selecciona Informe2_datos-de-bodega. En Permissions → Repository permissions → Contents elige "Read and write". Ponle una fecha de vencimiento y genera el token (empieza con github_pat_).
